# Rajeeb Pramanik — Portfolio

A single-page, interactive portfolio site showcasing projects, research, certifications, and experience in AI/ML and software development.

## Features
- Dark, AI-lab-inspired design with an animated particle-network background
- Typing-effect hero section, scroll-reveal animations, and filterable project cards
- Certification gallery with a click-to-expand lightbox (real certificate images embedded)
- Fully self-contained — all images and the resume PDF are embedded as base64 data URIs, so the site is a single `index.html` file with no external dependencies

## Live Site
Once GitHub Pages is enabled on this repo (Settings → Pages → Source: `main` branch, `/ (root)` folder), the site will be live at:

```
https://<your-github-username>.github.io/portfolio-site/
```

## Tech
Plain HTML, CSS, and vanilla JavaScript — no build step, no dependencies. Just open `index.html` in a browser or deploy as-is to any static host (GitHub Pages, Netlify, Vercel, etc.).
